# MicroCoin Network

![Version](https://img.shields.io/badge/version-1.0.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)
![Platform](https://img.shields.io/badge/platform-Arduino%20%7C%20ESP32%20%7C%20Python-lightgrey)

**MicroCoin** is a next-generation blockchain network combining **Proof of Masked Authentication (PoMA)** with **Proof of Stake (PoS)**. It features a unique level-based staking system, real ECDSA cryptography (secp256k1), and supports miners on ESP32, Arduino Uno, and PC.

---

## 🚀 Features

| Feature | Description |
|---------|-------------|
| **Hybrid Consensus** | PoMA + PoS for security and efficiency |
| **Level Staking** | Every 100 MC staked = 1 level. Higher level = faster blocks |
| **Real Cryptography** | ECDSA secp256k1 signatures (same as Bitcoin) |
| **Slashing Mechanism** | 10% stake penalty for missed signatures |
| **Multi-Platform** | ESP32, ESP8266, Arduino Uno, PC (Windows/Linux/macOS) |
| **Reward Distribution** | 75% validators / 8% nodes / 7% uptime / 10% liquidity providers |
| **Discord Bot** | Liquidity contributions, wallet linking, leaderboards |
| **Web Wallet** | Generate and manage wallets in browser |
